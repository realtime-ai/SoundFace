# SoundFace

> 开发进展（2026-10-18）：SoundFace Studio 工作台、默认角色与参考图导入、虚拟麦及虚拟摄像头已接入。腾讯会议本机数字人视频采集和远端声音接收已通过；视频远端接收、长时间稳定性及正式签名发布仍待验收。界面统一使用 SoundFace 品牌；API 服务商仅作为底层能力。构建与验收见 [开发版说明](docs/DEVELOPMENT.md) 和 [验收记录](docs/VERIFICATION.md)。以下产品定义保留为 2026-10-15 基线。

SoundFace 是面向 macOS 的实时音视频形象工具：通过预设变声、降噪和背景替换，将处理后的声音与画面输出为虚拟麦克风和虚拟摄像头，供会议、直播和录制软件使用。

## 目标用户

- 远程办公、线上授课与会议用户：让声音更清楚，减少真实环境背景的干扰。
- 主播与内容创作者：使用稳定的声音预设和画面背景，快速切换出镜风格。
- 教程、演示与视频录制用户：在常用录制工具中直接获得处理后的音视频输入。

## 首版范围

首版聚焦 macOS，打通“输入 → 实时处理 → 系统虚拟设备 → 第三方应用”的完整链路。

| 链路 | 首版能力 | 输出 |
| --- | --- | --- |
| 音频 | 麦克风输入、降噪、有限数量的预设变声、开关与试听 | SoundFace 虚拟麦克风 |
| 视频 | 摄像头输入、人物分割、静态背景替换、画面预览 | SoundFace 虚拟摄像头 |
| 控制 | 输入设备选择、效果预设、运行状态、权限与安装引导 | 统一桌面控制面板 |

用户在会议、直播或录制软件中选择 SoundFace 虚拟设备即可接入；具体应用兼容性需要逐项验证，不承诺覆盖所有软件。录制与直播推流由现有工具完成。

## 首版明确不做

- 零样本声音克隆、任意人物声音复刻。
- Live2D 模型导入、表情捕捉与角色驱动。
- 同声传译、实时翻译及跨语言语音生成。
- 数字人、换脸、全身虚拟形象与生成式口型驱动。

以上能力放入后续探索，不是首版依赖或已承诺的交付内容。

## 技术与分发方向

- Electron + React 负责控制界面和预览；实时处理由 Swift / Objective-C++ / C++ 原生引擎承担。
- 虚拟摄像头使用 CoreMediaIO Camera Extension；虚拟麦克风使用 Core Audio AudioServerPlugIn。
- 采用“轻本地、重云端”：基础实时处理与设备输出留在本地，重模型能力后续按需接入云端。
- 以官网签名、公证的 pkg 安装包为主要分发方式；App Store 的功能范围和可行性单独评估。
